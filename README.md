# task-cli

## Giới thiệu
Công cụ quản lý công việc trên dòng lệnh, hỗ trợ các lệnh: `add`, `list`, `done`, `delete`.

## Cách tải và chạy
```bash
git clone [https://github.com/kiennt-dev/task-cli.git](https://github.com/kiennt-dev/task-cli.git)
cd task-cli
python main.py list
```

## Ví dụ gõ từng lệnh
```bash
python main.py add "Viec 1"
python main.py list
python main.py done 1
python main.py delete 1
```
